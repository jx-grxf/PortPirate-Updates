# PortPirate Updates

Public signed Sparkle update feed and downloads for PortPirate.

This repository intentionally contains only release artifacts:

- `appcast.xml`
- `beta/appcast.xml`
- `releases/PortPirate-<version>.dmg`
- `releases/PortPirate-<version>.zip`
- `release-notes/<version>.md`
- `release-notes/<version>.html`

Source code lives in the private PortPirate repository. Update authenticity is enforced by Sparkle signatures, not by hiding these files.
